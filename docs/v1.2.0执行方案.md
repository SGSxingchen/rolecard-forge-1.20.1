# v1.2.0 世界任务/副本公告执行方案

## 目标
在不改变角色卡数据版本和既有网络语义的前提下，新增服务器世界级任务公告的展示、管理员编辑和同步功能，并发布正式版 `v1.2.0`。

## 明确边界
本模组仅保存、展示、编辑和同步公告；不实现任务判定、自动进度、世界协调、周目、传送、奖励、道具继承或联网数据库。

## 工作流
1. 审查现有架构、界面和 CI。
2. 用 SavedData、服务接口、追加 S2C/C2S 包和 `/rolecard mission` 实现服务器权威公告。
3. 增加任务查看与管理员管理界面、语言资源和文档。
4. 审查、提交并推送 main。
5. 仅使用 GitHub Hosted Runner 构建和 Forge 运行验证；全绿后下载该运行的正式 Jar，校验并发布正式 Release。

## 保护项
`docs/发布v1.1.0核验记录.md` 为用户未跟踪文件，整个流程中不得修改、暂存、提交或删除。

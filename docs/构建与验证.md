# 构建与验证

## 执行边界

本项目的真实构建、纯逻辑探针、Forge 专服启动和 Forge 客户端启动只由 GitHub Actions 的 GitHub Hosted Runner 完成。本地环境只用于 Git、文本/YAML/Python 静态检查和 `gh` 查询；**不得**在本机运行 `gradle`、`gradlew`、Java、Forge 或 Minecraft 动态测试。

历史 `build/` 目录只能帮助排查，不能证明当前提交已通过验证。推送后应在 Actions 页面确认本次提交对应的 run，而不是引用旧 run 或本地输出。

## CI 构建与发布边界

推送 main、提交 PR 或手动触发会运行 [持续集成工作流](../.github/workflows/ci.yml)。Hosted Runner 使用 Java 17 执行：

```text
./gradlew clean build --no-daemon
```

工作流只上传一个可发布 Jar，并排除 sources、javadoc、dev、plain 和 CI 测试探针 Jar；随后检查 Jar 内的 `META-INF/mods.toml` 与 `modId="rolecard"`，生成 SHA-256 清单。CI 只构建、校验和上传工件，**不会**创建 Git tag 或 GitHub Release，更不会覆盖 v1.0.0 Release。

## v1.1.0 / v1.1.1 / v1.1.2 自动验证范围

除静态门禁、Java 17 构建、真实 Forge 专服和 Xvfb/Mesa 客户端冒烟外，本版应在 Hosted Runner 中执行纯逻辑测试或仅 CI 的临时探针，至少断言：

1. v1.0.0 数据版本 1 NBT 迁移到版本 2，不丢身份与六维，新增字段有安全默认值；
2. 生平换行与合法 Unicode 可保存，控制/格式字符、超长度及网络包超限被拒绝或截断至安全结果；
3. 点数池守恒：玩家只能消费服务器保存的余额，单项保持 0–100，撤回和重新提交不复制点数；
4. 伪造总点数、旧 revision、重放提交、错误目标或错误状态均被服务端拒绝；
5. `DRAFT/PENDING/APPROVED/REJECTED` 只有合法迁移，重复 pending 幂等，不增长待审索引；
6. 管理员权限等级不足及越权审核被拒绝；
7. 反复应用六维 AttributeModifier 不累积，且不清除其他模组的 Modifier。
8. `verifyUiLayout` 对 320×240、427×240、854×480、1920×1080 断言安全区、页签/内容/反馈/底栏不重叠和最小点击空间；客户端探针依次打开玩家三页及管理员三页。
9. 九项当前属性的中英文友好名称兜底、三种 Modifier 运算、正/负/零与小数格式、草案预览、多行 tooltip 和普通摘要不泄漏内部键；客户端 Smoke 初始化六维 tooltip 数据。

`regression-report` 是最终结论：任一必需 Job（其中 `quality-gates` 已包含新增逻辑探针）失败、跳过或缺失，本次验证即为失败。详细 Job 关系、工件和覆盖判定见[持续集成与验证矩阵](持续集成与验证矩阵.md)。

## 人工联机验收清单

使用同一 CI 发布 Jar 启动 Forge 1.20.1 / 47.4.10 专服，并至少让一名普通玩家和一名权限等级 2 管理员加入：

1. 管理员发点，玩家在 320×240、常见 GUI Scale 与高分辨率下填写身份、生平（换行、滚动、字数）、分配/撤回六维并查看实际增益。
2. 验证余额不足、六维上下界、提交后的状态与默认锁定；断线重连、重开窗口、旧窗口再次保存都不能造成点数复制或覆盖新版本。
3. 玩家提交后，在线管理员收到含原版名、角色名、时间、状态的可点击通知；点击打开正确玩家的审核面板，并可批准、退回（含原因）、调整保存和解锁。
4. 管理员离线时提交，随后管理员登录，确认待审核数量提示、`/rolecard review list` 与目标上线后的 `review open` 行为正确；重复提交同一卡不产生重复项。
5. 用权限等级 0 与 2 分别验证命令、审核面板和恶意/过期网络请求的拒绝与成功。
6. 验证死亡重生、退出重连、主世界/下界/末地换维后角色卡、状态、余额、属性、生命值与同步结果正确。
7. 依次检查头顶、聊天、Tab 的 `VANILLA`、`ROLE`、`HIDDEN` 三种配置，以及两客户端显示一致性；与装备、药水及目标整合包的名称/属性模组叠加，确认 Modifier 不累积。
8. 用中文和英文客户端分别打开玩家与管理员六维页：检查名称本地化、固定值/百分比、点 `+/-` 后增益预览更新、长 tooltip 在左右边缘不越界，以及 Shift 高级标识只在按住时出现。

联网、数据库、网页展示、跨任务世界、道具继承和离线目标的客户端强制审核界面不在本版本实现范围。未来远端 DTO 边界见[未来同步设计](未来同步设计.md)。

# v1.2.0 世界任务／副本公告说明

## 功能与边界

世界任务是服务器当前的全局公告，使用 Overworld 的世界级 `SavedData` 保存；随世界备份迁移，不属于任何玩家角色卡或审核状态。模组只负责公告的展示、人工编辑与服务器同步，**不实现**任务判定、进度检测、世界/周目协调、传送、奖励、掉落或道具继承。

公告字段包括任务标题、可换行简介、目标列表（完成标记由管理员手动设置）、规则、备注、副本名称与可选编号、难度、人数、时限、状态、修订、更新时间与编辑者摘要。服务端会过滤控制/格式字符，限制总文本、单项和列表数量；客户端只读缓存拒绝较低 revision 的延迟快照。

## 玩家与管理员流程

1. 玩家按 **I**，在档案册第四个“世界任务”页签查看当前公告；正文区域可滚动，320×240 仍保留底栏安全区。
2. 管理员使用 `/rolecard mission edit` 打开原生任务管理面板，按基本、简介、目标、规则分页填写，再点击“发布任务”。
3. 服务器核对权限等级 2、revision、字段类型与长度；有效变更持久化并广播在线玩家。相同内容不会重复广播。
4. 普通玩家可用 `/rolecard mission view`；其余任务修改命令会被拒绝。`clear` 仅清空公告，不删除角色卡数据。

## 外部系统安全接入

`MissionBoardService` 是服务端主线程上的薄边界：外部任务模组可获取快照，或带当前 revision 调用受控 replace/update。交换数据使用 `MissionBoardSnapshot`（DTO/codec），不可直接改 SavedData、静态 Map 或客户端缓存。未来远端数据库、联网验证或第三方任务模组必须在服务端主线程回调、再次核对 revision 与权限；本版本不引入 HTTP、数据库或任何联网依赖。

## 人工测试清单

- 在 320×240、427×240、854×480、1920×1080 打开任务页与管理页，确认页签、滚动、多行文字、按钮、Tooltip 和安全边距。
- 新世界无公告、发布、重复发布、clear、重启服务器、玩家登录与换维度后分别确认快照和 revision。
- 用非管理员分别尝试 edit/status/title/objective，确认拒绝；管理员命令与 UI 发布都确认在线玩家只收到一次可点击提示。
- 多管理员窗口并行保存，确认旧 revision 被拒绝；确认副本自由文本、中文与英文客户端显示正常。

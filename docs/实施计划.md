# 实施计划

## 范围边界

- 本模组只管理角色身份卡、六维数值、显示和属性修正；不实现世界协调、周目、奖励或物品继承。
- 使用 `rolecard` 作为稳定的小写 modid，Java 包为 `com.rolecard`。

## v1.0.0 已完成步骤

1. 建立 Forge 1.20.1 / Java 17 项目骨架。
2. 实现服务端 Capability、NBT、网络同步、生命周期及可扩展属性映射。
3. 实现原生客户端档案界面、显示事件、管理员命令和服务端配置。
4. 撰写使用与未来同步设计文档，执行 Gradle 构建并提交本工作区独立 Git 仓库。

## v1.1.0 交付范围

1. 将角色卡数据升级为版本 2：在不丢失 v1.0.0 身份和六维的前提下，补充人物生平、可分配点数、审核状态、退回原因与递增修订号。
2. 以服务器为唯一权威，实现草稿、待审核、已批准、被退回四态流转；玩家只提交自己的意图，服务器核算点数、版本和状态。
3. 在原生界面加入身份、生平、六维分页或等效布局；提供可用的多行生平编辑、点数加减、实际增益提示、提交和状态反馈。
4. 增加管理员点数、审核命令、点击通知与专用查看/编辑面板；专服公共代码不得加载客户端界面类。
5. 为离线管理员持久化待审核索引；登录提示待审数量，同一卡反复提交只更新同一待审记录。
6. 增加纯逻辑或 CI 临时探针，覆盖迁移、文本边界、点数守恒、重放拒绝、状态机、修订冲突、幂等、权限和属性不重复；更新 Hosted Runner CI 与验证文档。
7. 保留 `v1.0.0` 标签与 Release，不在本轮自动创建新标签或 Release；仅在主分支提交、推送和追踪 CI。

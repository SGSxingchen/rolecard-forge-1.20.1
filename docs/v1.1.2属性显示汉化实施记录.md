# v1.1.2 属性显示汉化实施记录

## 目标

修复角色卡普通界面泄漏 `max_health`、`attack_damage` 等内部属性键的问题，同时保持既有角色卡存档、网络协议与属性计算语义兼容。

## 实施方案

1. 新建客户端共用的属性显示格式化层，以客户端可翻译组件优先解析 `Attribute#getDescriptionId()`；原版及缺失翻译的属性均有角色卡语言键兜底。
2. 按 AttributeModifier 运算方式显示固定值或百分比，摘要与完整工具提示均基于当前值加本轮草案变化的预览值。
3. 玩家和管理员六维页复用摘要及多行工具提示；普通界面不显示内部键，按 Shift 才显示高级标识。
4. 为中文、英文补充语言资源，加入静态探针与客户端烟雾初始化覆盖，更新用户文档和版本号。
5. 不修改、不暂存、不提交 `docs/发布v1.1.0核验记录.md`；禁止本机 Gradle、Java、Forge 或 Minecraft 动态运行，完整验证仅使用 GitHub Hosted Runner。

## 显示规则

- 加法修正使用带正负号的固定值，例如“最大生命值 +2.40”；接近零的值统一显示 `+0`。
- 基础乘法和总乘法换算为百分比，例如“移动速度 +2.4%”；不显示裸小数。
- 摘要显示首项和总项数；完整 tooltip 一行一个映射，并在草案变化时以“当前 → 拟提交”标明预览。
- 通过原生 `renderComponentTooltip` 显示列表，交给游戏处理屏幕边缘避让；普通文本不包含属性注册键。

## 验证记录

静态质量门禁、既有 v1.1.0 逻辑探针和新增 v1.1.2 属性显示探针可在本地以 Python 读取源码/资源执行；真实构建、专服与客户端 Smoke 仅由推送后的 GitHub Hosted Runner 执行。
